# SaaS-Revenue-Analytics-Dashboard
Tools: Tableau Public
Project description: Created an interactive analytical dashboard in Tableau Public to analyze key metrics of a SaaS business. The dashboard allows tracking Revenue trends, the number of Paid Users, and ARPPU, analyzing trends, and comparing metrics across different periods.
Main tasks and work done:
• Connected and prepared data in Tableau Public, created a new Workbook.
• Built basic visualizations: line and bar charts.
• Created calculated fields to compute key metrics:
- Total Revenue — total income;
- Paid Users Count — number of paid users;
- ARPPU — average revenue per paying user.
• Used Dimensions and Measures for grouping, aggregating, and analyzing data.
• Used color coding for visual comparison of metrics.
• Created more complex visualizations: Box Plot and combined charts.
• Built an interactive dashboard by combining several worksheets.
• Set up filters for dynamic data analysis.
• Formatted dates: displayed in Month/Year format, sorted chronologically, and aggregated at the monthly level.
• Published the dashboard on Tableau Public and configured access to it.
Project result:
Developed an interactive SaaS Revenue Dashboard that combines key business metrics in one interface and provides convenient analysis of revenue trends, paid user numbers, and ARPPU.
The project helped deepen practical skills in using Tableau Public, creating calculated fields, analytical visualization, and building interactive dashboards.
